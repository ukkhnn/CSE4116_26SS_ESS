# PRJ2 — 블록 단위 FTL

`src/address_translation.c`와 `.h`는 제출한 두 파일입니다. 전체 SDK 프로젝트를 복제한 폴더가 아니라, 해당 실습 펌웨어 작업공간에 적용하는 교체 파일입니다.

## 주소 변환을 읽는 순서

1. `logicalSliceAddr`에서 논리 블록 번호와 블록 안의 offset을 구합니다.
2. `AddrTransRead`는 논리 블록 첫 슬라이스의 매핑을 읽고 offset을 더합니다.
3. `AddrTransWrite`는 새 위치를 할당하고, offset이 0일 때 블록의 기준 매핑을 기록합니다.
4. 역방향 매핑은 매 쓰기마다 갱신됩니다. 가비지 컬렉션이 사용하는 정보입니다.

헤더는 PRJ1 제출 펌웨어와 같고, C 파일의 읽기·쓰기 주소 변환이 달라졌습니다. 코드를 비교할 때는 [PRJ1 펌웨어](../prj1/firmware/address_translation.c)를 출발점으로 삼을 수 있습니다.

## 검증 범위

두 파일은 보관된 제출 압축 및 중복 사본과 바이트 단위로 일치합니다. 실제 실습 환경의 설정, 순차/임의 쓰기와 가비지 컬렉션에서의 동작은 이번 정리에서 실행하지 않았습니다. 블록 기준 매핑이 연속 위치를 가리킨다는 전제를 포함한 동작 설명이며, 이 README가 새 성능 검증을 뜻하지는 않습니다.
